隐私政策

运营智脑 OpsCompass · 生效日期：2026-10-02 · 版本：v1.0
核心承诺：运营智脑是本地部署型软件。您的业务数据默认存储在您自己的设备与数据库中，我们（开发者）不收集、不上传、不查看任何业务数据，也不含广告与第三方埋点。

一、适用范围

本政策适用于由 BY LAOMENG 网络工作室（以下称“我们”）开发并发布的运营智脑 OpsCompass 桌面端、Web 端及由此衍生的 Microsoft Store 版本。软件以本地部署方式运行，服务端由使用者自行部署。

二、我们如何处理数据

  • 业务数据：导入的运营数据、指标、报表等，全部存储在使用者自行部署的本地数据库（PostgreSQL）与本地文件系统中，不经过我们的服务器。
  • 账号与登录信息：账号、加密后的口令、访问令牌保存在本地服务端，用于身份校验，不上传至第三方。
  • 操作日志：安全审计日志保存在本地，保留期限可由使用者在配置中调整（默认 180 天）。
  • 本地缓存：为支持离线可用，应用会在浏览器 / 设备本地缓存界面静态资源（HTML、样式、图标等），不缓存业务接口数据。

三、AI 能力与数据流向

软件的 AI 分析能力提供两种模式，由使用者在配置中自行选择：

  • 本地模式（默认）：调用本机运行的本地大模型，数据不出设备。
  • 云端 API 模式：由使用者自行填写第三方模型服务地址与密钥，此时相关文本数据将发送至使用者自行选定的服务商，其处理规则适用该服务商的政策。我们不参与、不代理、不留存该链路数据。

四、我们不做什么

  • 不收集个人身份信息、设备指纹、地理位置；
  • 不内置广告、行为分析 SDK 或遥测上报；
  • 不向任何第三方出售、出租或共享您的数据。

五、您的权利

  • 查阅与导出：数据均在本机，可随时通过软件界面或数据库直接查阅、导出。
  • 删除：卸载软件并删除数据目录、数据库即可彻底清除全部数据。
  • 撤回授权：可随时在配置中关闭 AI 能力或切换回本地模式。

六、数据安全

软件提供口令强度校验、登录失败锁定、IP 白名单、操作审计等安全机制。因软件为本地部署，最终安全强度亦取决于使用者的部署环境（网络隔离、主机安全、备份策略）。

七、儿童隐私

本软件面向企业与运营从业者，不面向 13 岁以下儿童，也不会有意收集儿童信息。

八、政策更新

本政策如有更新，我们会在软件仓库与发布页面同步最新版本并更新生效日期。重大变更将在应用内提示。

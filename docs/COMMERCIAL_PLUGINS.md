# 官方商业插件

> 版本：v0.12.0 起 | 更新：2026-10-11

运营智脑（OpsCompass）的**官方商业插件**随商业版订阅分发，不包含在本开源仓库内。本页仅作声明，不涉及实现细节。

## 当前官方商业插件

| 插件 | 版本 | 说明 |
|---|---|---|
| 舆情监控 | v0.12.0（MVP）→ v0.13.0（完整版） | 风险域官方商业插件，覆盖监测—分析—预警—报告全链路 |
| 危机公关 | v0.12.0（MVP）→ v0.13.0（完整版） | 风险域官方商业插件，覆盖定级—SOP—口径审批—复盘全链路 |

## 获取方式

- 商业插件以**加密插件包**形式交付，安装时须通过**授权码校验**，随商业版订阅分发
- 社区开发者可通过公开插件 SDK 自行开发**社区插件**，走开源插件市场上架/安装/校验流程
- 插件市场协议与 SDK 开源，市场服务端为商业服务

## 边界声明

- 商业插件必须通过公开插件接口挂载，遵循开源仓库内公开的插件清单规范与 SDK 约束
- 商业插件设计文档存放于私有目录，不进入本仓库
- 本开源仓库不提供商业插件的下载、安装包或实现代码

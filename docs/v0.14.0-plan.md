### 1.6 竞品共性趋势（总结）

1. **AI 智能洞察**是标配：看板/卡片智能总结、异常识别、自动生成报告。
2. **预测类能力**成主战场：流失预测、转化预测、Lookalike 人群扩散。
3. **从"分析"走向"执行"**：运营智能体一句话驱动全流程，双 Agent（分析+执行）协同。
4. **知识沉淀**：业务经验、运营策略沉淀为可复用资产（知识库/SOP/Agent 模板）。
5. **场景化封装**：面向门店、活动、生命周期等具体场景出开箱即用的 Agent。
6. **数据安全与治理**同步升级：传输加密、权限管控、血缘、合规审计。

## 四、v0.14.0 规划内容（明显迭代：新页面 + 新角色 + 新数据源）

### 4.1 新页面（2 个）

| 页面 | 功能 | 对应竞品 |
|---|---|---|
| **InsightCenter（智能洞察中心）** | Dashboard 级 AI 总结、异常波动识别与归因、可行动建议列表、洞察→一键转任务 | 观远仪表板洞察 / 火山看板智能总结 |

### 4.2 新角色（2 个）

| 角色 | 能力 | 说明 |
|---|---|---|
| **分析 Agent（Insight Agent）** | 采集数据、诊断分析、生成洞察与建议，只读不改 | 对标探域"运营 Agent"、神策"ML Agent" |
| **执行 Agent（Action Agent）** | 经人工确认后执行具体动作并交付结果（对接插件市场动作插件） | 对标探域"运助 Agent" |

双 Agent 协同：分析 Agent 产出洞察 → 用户确认 → 执行 Agent 落地 → 结果回写事件总线。

| 广告投放数据源 | 连接器插件 | 渠道 ROI、人群扩散种子 |

## 七、风险与对策

| 风险 | 影响 | 对策 |

## 八、总结

v0.14.0 的核心是**把已落地的内核能力升级为可感知的智能决策闭环**：InsightCenter 承接"洞察"，DecisionStudio 承接"执行"，分析 Agent + 执行 Agent 双角色形成"诊断→确认→落地→回写"闭环，预测引擎与知识库补齐竞品已具备、我们尚缺的 AI 决策底座。同时守住差异化：本地优先、插件生态、内核事件驱动、模型路由——这是 SaaS 竞品无法复制的优势。
